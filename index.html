Conectar una API de IA

Usa un endpoint compatible con la API de chat de OpenAI. La clave se guarda solo en la sesión de este navegador y se envía al proveedor configurado; no se incluye en el repositorio.

⚠️ La conexión directa desde el navegador depende de que el proveedor permita CORS. Para producción, usa un backend propio como proxy y no expongas claves en una web pública.
